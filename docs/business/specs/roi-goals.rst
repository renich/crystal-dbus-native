=================
ROI & Key Metrics
=================

Measurable Objectives
---------------------

#. **Zero C-Library Runtime Dependencies**: Eliminate external ``libdbus`` linking requirements while supporting pure Crystal UNIX domain socket transport.
#. **Complete Wire & Body Type Safety**: Marshal and unmarshal all basic and nested D-Bus types (`Variant`, `StructValue`, `ObjectPath`, `Signature`, `UnixFD`, `Array`, and `Hash`) with strict alignment enforcement.
#. **Zero Initial Defects**: Enforce 100% pass rates across Crystal specs, Ameba static analysis, Flaw security scanning, and ``crstlint``/``rstcheck`` documentation gates.
